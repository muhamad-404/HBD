# Background Music

Place a royalty-free `background-music.mp3` file in the **`public/audio/`** folder (not here).

Path on disk: `public/audio/background-music.mp3`

The site works fully without it — audio controls hide automatically when no valid file is detected.

## URLs after deployment

- Local dev: `http://localhost:5173/audio/background-music.mp3`
- GitHub Pages: `https://muhamad-404.github.io/HBD/audio/background-music.mp3`

## Recommendations

- Use a track you have the rights to (royalty-free, Creative Commons, or your own)
- Keep file size reasonable for mobile (under 3–5 MB if possible)
- Soft, dreamy instrumental works best for this experience
